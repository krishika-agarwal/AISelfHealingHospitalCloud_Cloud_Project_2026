# Objectives

1. Design a scalable AWS-based cloud architecture for Hospital Information Systems that supports secure deployment, continuous monitoring, and high service availability.

2. Develop an AIOps-based monitoring framework capable of continuously analyzing cloud infrastructure metrics and logs to detect abnormal system behaviour in real time.

3. Integrate Explainable AI (XAI) techniques to generate interpretable explanations for detected anomalies, enabling administrators to better understand their possible root causes and support informed decision-making.

4. Design an automated self-healing mechanism that initiates predefined recovery actions for detected infrastructure anomalies, reducing manual intervention and minimizing system downtime.

5. Implement appropriate cloud security measures using AWS services to safeguard healthcare applications, cloud resources, and operational data while supporting reliable system operation.

6. Evaluate the proposed framework using suitable datasets and monitoring metrics to assess its effectiveness in terms of anomaly detection, explanation quality, recovery time, and overall system reliability.
